  <action>
    Create src/app/routers/cmis.py with CMIS 1.1 Browser Binding endpoints. Per CMIS spec, Browser Binding uses:
    - GET requests with `cmisselector` query param for reads
    - POST requests with `cmisaction` form param for writes

    Router prefix: "/cmis/browser" (no tags overlap with internal API)
    All endpoints require get_current_user dependency for auth (CMIS-04).

    Endpoints to implement:

    1. GET / — Repository info (cmisselector not needed, returns repo info JSON)
       Calls cmis_service.get_repository_info. Root folder ID: query DB for first cabinet or create a "Root Folder" cabinet.

    2. GET /root — getChildren of root folder
       Redirect/alias to GET /{folderId}?cmisselector=children where folderId is root folder

    3. GET /root/{object_id} — getObject
       cmisselector param determines behavior:
       - "object" (default): return CMIS object (auto-detect document vs folder by trying document first, then folder)
       - "children": return children if folder (getChildren) — call folder_service.list_children, map each to CMIS format
       - "descendants": return descendants tree (getDescendants) — recursive folder tree in CMIS format
       - "parents": return parent folders of object (getObjectParents) — for documents return folders containing it, for folders return parent
       - "content": stream document content (getContentStream) — call document_service.download_document

    4. POST /root — create object in root folder
       cmisaction form param determines behavior:
       - "createDocument": multipart with file + cmis:name property -> call document_service.upload_document, file to folder via folder_service.file_document
       - "createFolder": form with cmis:name -> call folder_service.create_folder

    5. POST /root/{object_id} — actions on existing object
       cmisaction form param:
       - "update": update properties -> call document_service.update_document with from_cmis_properties
       - "delete": delete object -> call document_service.delete_document or folder_service.delete_folder
       - "move": move object (requires sourceFolderId, targetFolderId) -> unfile from source, file to target
       - "checkOut": checkout document -> call document_service.checkout_document
       - "checkIn": checkin with file -> call document_service.checkin_document
       - "cancelCheckOut": cancel checkout -> release lock (set locked_by=None, locked_at=None, flush)

    Response format: All responses return JSON with succinctProperties (CMIS Browser Binding "succinct" mode). Do NOT use the verbose properties format.

    Error mapping: Map HTTPException status codes to CMIS error format: {"exception": "objectNotFound"|"invalidArgument"|"constraint"|"permissionDenied"|"notSupported", "message": str}
