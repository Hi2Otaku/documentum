<objective>
Build the complete backend for document import/export: Pydantic schemas, service layer, Celery tasks, and API endpoints. Export creates ZIP packages with content files, metadata JSON manifest, folder hierarchy, ACLs, and relationships. Import reads ZIP packages, recreates documents/folders, and resolves conflicts using skip/overwrite/rename strategies. Both operations run as background jobs reusing the BulkJob model from Phase 40.

Purpose: Enables migration, backup, and cross-environment transfer of document packages.
Output: Working API endpoints at /api/v1/import-export/* with Celery-backed async processing.
</objective>

    **3. Create src/app/tasks/import_export.py:**

    Follow the exact pattern from bulk_operations.py: `@celery_app.task` with `asyncio.run(_execute_async(...))`.

    **Export task (`execute_export_job`):**
    - Load BulkJob, mark as running
    - Collect all document IDs: from `document_ids` directly + recursively from `folder_ids` (query document_folders for each folder, recurse into child folders)
    - Build manifest.json structure:
      ```json
      {
        "version": "1.0",
        "exported_at": "ISO timestamp",
        "exported_by": "user_id",
        "documents": [
          {
            "id": "original_uuid",
            "title": "...", "author": "...", "filename": "...",
            "content_type": "...", "custom_properties": {...},
            "lifecycle_state": "...", "document_type_id": "...",
            "content_file": "docs/{uuid}/{filename}",
            "version": {"major": 0, "minor": 1}
          }
        ],
        "folders": [
          {"id": "uuid", "name": "...", "parent_id": "uuid|null", "is_cabinet": false, "description": "..."}
        ],
        "folder_filings": [
          {"document_id": "uuid", "folder_id": "uuid"}
        ],
        "acls": {
          "documents": [{"document_id": "...", "principal_id": "...", "principal_type": "...", "permission_level": "..."}],
          "folders": [{"folder_id": "...", "principal_id": "...", "principal_type": "...", "permission_level": "..."}]
        },
        "relationships": [
          {"source_document_id": "...", "target_document_id": "...", "relationship_type": "...", "description": "..."}
        ]
      }
      ```
    - For each document: download latest version content from MinIO (download_object with minio_object_key), write to ZIP at `docs/{doc_id}/{filename}`
    - Write manifest.json to ZIP root
    - Upload completed ZIP to MinIO at `exports/{job_id}.zip`
    - Update BulkJob: status="completed", parameters.zip_object_key = "exports/{job_id}.zip", success_count, failure_count
    - Per-document try/except for partial failure (same pattern as bulk_operations.py)

    **Import task (`execute_import_job`):**
    - Load BulkJob, mark as running
    - Download ZIP from MinIO temp key in parameters.zip_key
    - Parse manifest.json from ZIP
    - Phase 1 -- Create folders (if any in manifest): Map old folder IDs to new UUIDs. Create folders in parent-first order. If target_folder_id set, reparent root-level folders under it.
    - Phase 2 -- Create documents with conflict resolution:
      - For each doc in manifest.documents:
        - Check for conflict: query by title in target folder (or globally if no folder)
        - strategy="skip": log skip, continue
        - strategy="overwrite": update existing document metadata, upload new version content
        - strategy="rename": append " (imported)" to title, create new document
        - On create: read content from ZIP at content_file path, call upload_object to MinIO, create Document + DocumentVersion rows
      - Map old document IDs to new UUIDs
    - Phase 3 -- File documents into folders using folder_filings + ID mappings
    - Phase 4 -- Recreate ACLs if present (map document/folder IDs via mappings)
    - Phase 5 -- Recreate relationships if present (map source/target doc IDs, skip if either unmapped)
    - Update BulkJob with results, counts, status
    - Delete temp ZIP from MinIO

    **1. Create src/app/routers/import_export.py:**

    Follow the exact pattern from routers/bulk.py. Prefix: `/import-export`, tags: `["import-export"]`.

    Endpoints:
    - `POST /import-export/export` -- Accept ExportRequest JSON body. Call `import_export_service.create_export_job(db, req, user_id)`. Return 202 with EnvelopeResponse[ImportExportJobResponse].
    - `POST /import-export/import` -- Accept multipart form: `file: UploadFile` + `target_folder_id: str | None = Form(None)` + `conflict_strategy: str = Form("skip")`. Read file bytes, validate it is a ZIP (check magic bytes or try zipfile.is_zipfile). Call `import_export_service.create_import_job(db, file_bytes, ImportRequest(...), user_id)`. Return 202.
    - `GET /import-export/jobs` -- Paginated list of import/export jobs for current user. Use `import_export_service.get_import_export_jobs()`. Return EnvelopeResponse with PaginationMeta.
    - `GET /import-export/jobs/{job_id}` -- Single job detail. Return 404 if not found.
    - `GET /import-export/download/{job_id}` -- For completed export jobs only. Read zip_object_key from job.parameters, download from MinIO via download_object, return StreamingResponse with content_type="application/zip" and Content-Disposition header with filename "export_{job_id}.zip". Return 404 if job not found, 400 if job not completed or not an export.

    Use `Depends(get_current_user)` on all endpoints. Use `Depends(get_db)` for database session.

    Helper function `_job_response(job) -> ImportExportJobResponse` to convert BulkJob model (same pattern as bulk.py _job_response). Set download_ready=True when job.status=="completed" and job.job_type=="export" and job.parameters has zip_object_key.
