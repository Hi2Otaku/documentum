  Response 202: { data: ImportExportJobResponse }

POST /api/v1/import-export/import
  Body: FormData with file (ZIP), target_folder_id? (string), conflict_strategy ("skip"|"overwrite"|"rename")

GET /api/v1/import-export/jobs?page=N&page_size=N
  Response: { data: ImportExportJobResponse[], meta: PaginationMeta }

GET /api/v1/import-export/jobs/{job_id}
  Response: { data: ImportExportJobResponse }

GET /api/v1/import-export/download/{job_id}
  Response: application/zip stream

ImportExportJobResponse: {
  id, job_type ("export"|"import"), status ("pending"|"running"|"completed"|"failed"),
  total_count, success_count, failure_count,
  results: [{document_id, status, error?}] | null,
  created_by, created_at, completed_at,
  download_ready: boolean
}

  <action>
    **1. Create frontend/src/api/importExport.ts:**

    Follow the exact pattern from bulk.ts. Define:

    ```typescript
    interface ImportExportJobResponse {
      id: string; job_type: "export" | "import";
      status: "pending" | "running" | "completed" | "failed";
      total_count: number; success_count: number; failure_count: number;
      results: { document_id: string; status: string; error?: string }[] | null;
      created_by: string; created_at: string; completed_at: string | null;
      download_ready: boolean;
    }
    ```

    Query key factory: `importExportKeys = { all, list, detail }`.

    API functions:
    - `exportDocuments(params: { document_ids?: string[], folder_ids?: string[], include_acls?: boolean, include_relationships?: boolean })` -- POST JSON to /api/v1/import-export/export, return job response
    - `importPackage(file: File, targetFolderId?: string, conflictStrategy?: string)` -- POST FormData to /api/v1/import-export/import (use FormData, NOT JSON -- append file, target_folder_id, conflict_strategy). No Content-Type header (let browser set multipart boundary).
    - `fetchImportExportJobs(page?, pageSize?)` -- GET /api/v1/import-export/jobs with pagination
    - `fetchImportExportJob(jobId)` -- GET single job
    - `getExportDownloadUrl(jobId)` -- Return URL string `/api/v1/import-export/download/{jobId}` (download via anchor tag or window.open with auth)
    - `downloadExport(jobId)` -- fetch the download endpoint with auth headers, create blob URL, trigger download via hidden anchor element

    **2. Create frontend/src/components/browse/ExportDialog.tsx:**

    A dialog component using shadcn Dialog. Props: `{ open, onOpenChange, selectedDocumentIds?: string[], selectedFolderIds?: string[] }`.

    Contents:
    - Title: "Export Package"
    - Two checkboxes: "Include ACLs" (default checked), "Include relationships" (default checked)
    - Summary text: "Exporting {N} documents" or "Exporting {N} folders" based on props
    - Export button that calls `exportDocuments(...)` via useMutation, shows toast on success ("Export job started"), closes dialog
    - Loading state on button during mutation

    **3. Create frontend/src/pages/ImportExportPage.tsx:**

    Admin page with two sections:

    **Import Section (top):**
    - File upload input (accept=".zip") with drag-and-drop zone (styled div with dashed border)
    - Target folder ID input (optional text field, or "Root" default)
    - Conflict strategy radio group: Skip (default), Overwrite, Rename -- use shadcn RadioGroup
    - "Import" button -- calls importPackage via useMutation, shows toast, resets form
    - Disabled state while uploading

    **Job History Section (bottom):**
    - Table showing import/export jobs using useQuery with fetchImportExportJobs
    - Columns: Type (Export/Import badge), Status (colored badge: pending=yellow, running=blue, completed=green, failed=red), Total, Success, Failed, Created, Actions
    - Actions column: "Download" button for completed exports (calls downloadExport), "View Details" expanding row showing per-item results
    - Auto-refresh: use refetchInterval: 3000 when any job has status "pending" or "running" (same pattern as BulkJobsPage.tsx conditional polling)
    - Pagination controls

    Use shadcn components: Card, Button, Input, RadioGroup, Table, Badge, Dialog.
    Use lucide-react icons: Download, Upload, Package, FileArchive.
