    1. Create src/app/models/identity_provider.py with two models:
       - IdentityProvider(BaseModel): __tablename__="identity_providers", columns: name (str unique), provider_type (enum: "ldap", "saml", "oidc"), config (JSON — stores connection details like metadata_url, client_id etc), is_enabled (bool default False), created_at/updated_at via BaseModel
       - ServiceToken(BaseModel): __tablename__="service_tokens", columns: token_hash (str, unique index), name (str — descriptive label like "celery-worker"), user_id (FK to users.id — the service account this token acts as), is_active (bool default True), expires_at (datetime nullable — null means no expiry), last_used_at (datetime nullable)

    2. Create src/app/core/auth_backend.py with Strategy pattern:
       - Abstract base: AuthBackend with async method `validate_token(token: str, db: AsyncSession) -> User | None`
       - LocalAuthBackend: calls decode_access_token, looks up user by sub claim (same logic as current get_current_user but returns None instead of raising)
       - ServiceTokenBackend: hashes incoming token with SHA-256, looks up in service_tokens table by token_hash, returns the associated user. Updates last_used_at. Check is_active and expires_at.
       - AuthBackendRegistry class: holds list of backends, iterates them in order calling validate_token until one returns a User. Order: LocalAuthBackend first, then ServiceTokenBackend.
       - Module-level instance: `auth_backend_registry = AuthBackendRegistry([LocalAuthBackend(), ServiceTokenBackend()])`

    3. Create Alembic migration (raw DDL pattern matching phase 35):
       - Table identity_providers with columns: id (uuid PK), name (varchar 150 unique), provider_type (varchar 20), config (jsonb default '{}'), is_enabled (boolean default false), is_deleted (boolean default false), created_at (timestamp with tz), updated_at (timestamp with tz)
       - Table service_tokens with columns: id (uuid PK), token_hash (varchar 128 unique index), name (varchar 255), user_id (uuid FK users.id), is_active (boolean default true), is_deleted (boolean default false), expires_at (timestamp with tz nullable), last_used_at (timestamp with tz nullable), created_at (timestamp with tz), updated_at (timestamp with tz)
       - Get the latest alembic revision from existing migrations for the down_revision chain

    4. Add to src/app/core/config.py:
       - service_token_prefix: str = "svc_" (prefix for service tokens to distinguish from JWTs)
