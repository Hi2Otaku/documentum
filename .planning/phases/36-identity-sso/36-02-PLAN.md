    2. Create src/app/services/identity_service.py with:
       - CRUD for IdentityProvider: create_provider, get_provider, list_providers, update_provider, delete_provider
       - jit_provision_user(db, username, email, groups_list, provider_name) -> User:
         * Check if user exists by username. If yes, update group memberships and return.
         * If no, create User with random hashed password (SSO users don't use local password), set is_active=True
         * Map group names from IdP to system Group objects, create missing groups, add user to groups
         * Create audit record for "user_provisioned" action
         * Return the User
       - handle_saml_response(db, saml_response_xml, provider_id) -> tuple[str, bool]:
         * Load IdentityProvider by id, parse config as SAMLConfig
         * Use python3-saml (OneLogin_Saml2_Response) to validate the SAML response XML against IdP metadata
         * Extract username, email, groups from attributes using attribute_mapping
         * Call jit_provision_user
         * Create local JWT via create_access_token(data={"sub": str(user.id), "username": user.username, "auth_source": "saml"})
         * Return (jwt_token, is_new_user)
       - initiate_saml_login(db, provider_id, relay_state) -> str:
         * Load provider, build SAML AuthnRequest redirect URL using python3-saml
         * Return the redirect URL to IdP
       - handle_oidc_callback(db, code, state, provider_id) -> tuple[str, bool]:
         * Load IdentityProvider by id, parse config as OIDCConfig
         * Use authlib to exchange authorization code for tokens (with PKCE verifier from state/session)
         * Validate ID token, extract claims using attribute_mapping
         * Call jit_provision_user
         * Create local JWT with auth_source="oidc"
         * Return (jwt_token, is_new_user)
       - initiate_oidc_login(db, provider_id) -> dict:
         * Load provider, generate PKCE code_verifier + code_challenge
         * Build authorization URL with client_id, redirect_uri, scopes, code_challenge, state
         * Return {"redirect_url": url, "state": state, "code_verifier": verifier}
       - sync_ldap_users(db, provider_id) -> dict:
         * Load provider, parse config as LDAPConfig
         * Connect to LDAP using ldap3 library
         * Search for users, search for groups
         * For each LDAP user: call jit_provision_user
         * Return {"synced_users": count, "synced_groups": count}
       - test_ldap_connection(db, provider_id) -> dict:
         * Attempt LDAP bind, return {"success": bool, "message": str}

       NOTE: For SAML, use try/except ImportError for python3-saml — if not installed, raise HTTPException 501 "SAML support not available". Same pattern for ldap3 and authlib. This allows the system to work without SSO dependencies installed (graceful degradation).

    3. Add to src/app/core/config.py:
       - sso_session_secret: str = "" (for PKCE state encryption, defaults to secret_key if empty)
       - frontend_url: str = "http://localhost:5173" (for SSO redirect after auth)
