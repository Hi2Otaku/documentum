Create `src/app/services/document_type_service.py` with these functions:

1. **`merge_schemas(parent_schema: dict, child_schema: dict) -> dict`**: Returns merged JSON Schema. Combine `properties` dicts (child overrides parent). Combine `required` arrays (union, deduplicated). Wrap in `{"type": "object", "properties": {...}, "required": [...]}`.

2. **`get_effective_schema(doc_type: DocumentType) -> dict`**: If `doc_type.parent_type` exists, call `merge_schemas(doc_type.parent_type.metadata_schema, doc_type.metadata_schema)`. Otherwise return `doc_type.metadata_schema` wrapped as `{"type": "object", ...}` if not already wrapped.

3. **`validate_metadata(db: AsyncSession, document_type_id: uuid.UUID | None, custom_properties: dict) -> None`**: If `document_type_id` is None, return immediately (untyped skip). Fetch the DocumentType (with parent eagerly loaded via selectin). Get effective schema. Use `jsonschema.Draft7Validator(schema).iter_errors(custom_properties)` to collect ALL errors. If errors, raise `HTTPException(status_code=422, detail={"message": "Metadata validation failed", "errors": [{"field": ..., "error": ...} for each error]})`. Field path: `".".join(str(p) for p in e.absolute_path) or e.json_path`.

4. **`create_document_type(db: AsyncSession, data: DocumentTypeCreate, user_id: str) -> DocumentType`**: Validate parent_type_id: if provided, fetch parent and verify `parent.parent_type_id is None` (no grandchild). If parent has a parent, raise HTTPException(400, "Cannot create type: parent type already has a parent (max 1 level inheritance)"). Also verify the name is unique (query by name, raise 409 if exists). Create and return.

5. **`list_document_types(db: AsyncSession) -> list[DocumentType]`**: Select all non-deleted types ordered by name. Use selectin for parent_type relationship.

6. **`get_document_type(db: AsyncSession, type_id: uuid.UUID) -> DocumentType`**: Fetch by ID, raise 404 if not found or is_deleted.

7. **`update_document_type(db: AsyncSession, type_id: uuid.UUID, data: DocumentTypeUpdate, user_id: str) -> DocumentType`**: Fetch, apply non-None fields. If parent_type_id is being changed, validate no grandchild. If this type has children (query for types where parent_type_id == type_id), prevent setting a parent on it (would create grandchild chain). Check name uniqueness if name is changing.

8. **`delete_document_type(db: AsyncSession, type_id: uuid.UUID) -> None`**: Soft delete (set is_deleted=True). Also set `document_type_id = None` on all documents referencing this type (unlink them).

9. **`get_document_count_for_type(db: AsyncSession, type_id: uuid.UUID) -> int`**: Count documents where `document_type_id == type_id` and `is_deleted == False`.

All functions use `from sqlalchemy import select, func` and `from sqlalchemy.ext.asyncio import AsyncSession`. Import `from fastapi import HTTPException, status`. Import `jsonschema` for validation. Import `from app.models.document_type import DocumentType` and `from app.models.document import Document`.
