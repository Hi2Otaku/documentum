5. **src/app/routers/documents.py** `get_document` and `list_documents`: Update the `DocumentResponse.model_validate(document)` calls to include `document_type_name`. Create a helper or use a dict merge: when the document has `document_type` relationship loaded, set `document_type_name = document.document_type.name if document.document_type else None`. The cleanest approach: after `DocumentResponse.model_validate(document)`, set `resp.document_type_name = document.document_type.name if document.document_type else None` -- but since Pydantic models are normally immutable, instead use `DocumentResponse.model_validate({**document.__dict__, "document_type_name": document.document_type.name if document.document_type else None})` or add it as a property resolver. Alternatively, use `model_validate` with a dict that includes the extra field.

   Simplest approach: In the Document model, the `document_type` relationship is `lazy="selectin"`, so it will be loaded. Create a helper function:
   ```python
   def _doc_response(doc: Document) -> DocumentResponse:
       data = DocumentResponse.model_validate(doc)
       data.document_type_name = doc.document_type.name if doc.document_type else None
       return data
   ```
   But Pydantic v2 models are frozen by default. So either:
   (a) Set `model_config = ConfigDict(from_attributes=True, frozen=False)` in DocumentResponse, OR
   (b) Use `DocumentResponse(**{...doc fields..., "document_type_name": ...})`.

   Best approach: Use `DocumentResponse.model_validate(doc).model_copy(update={"document_type_name": doc.document_type.name if doc.document_type else None})`.

   Apply this pattern in `upload_document`, `get_document`, `list_documents`, and `update_document` endpoint handlers in the router.
