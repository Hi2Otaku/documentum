2. **frontend/src/components/admin/CreateTypeDialog.tsx**:
   - Props: `open: boolean`, `onOpenChange: (open: boolean) => void`, `onSuccess: () => void`, `existingTypes: DocumentTypeResponse[]`.
   - Uses `Dialog` from shadcn/ui with `max-w-lg`.
   - Form fields: Name (Input, required), Description (Textarea), Parent Type (Select -- options are types from `existingTypes` that have `parent_type_id === null`, plus "None" as first option), Schema (SchemaEditor).
   - State: `name`, `description`, `parentTypeId`, `schemaText` (string), `schemaError` (string | null), `isSubmitting` (boolean).
   - On submit: Parse `schemaText` with `JSON.parse()`. If parse fails, set `schemaError` to "Invalid JSON: {error.message}". If parsed schema has no `properties` or `properties` is empty, set `schemaError` to "Schema must define at least one property". Otherwise call `createDocumentType({name, description, metadata_schema: parsed, parent_type_id: parentTypeId || null})`. On success: `toast.success("Type created")`, call `onSuccess()`, close dialog. On API error: `toast.error(message)`.
   - Submit button: "Save Type" (`Button` variant default), disabled while `isSubmitting`. Shows loading spinner during submit.
   - Cancel button: "Cancel" (`Button` variant outline).

3. **frontend/src/components/admin/EditTypeDialog.tsx**:
   - Props: `open: boolean`, `onOpenChange: (open: boolean) => void`, `onSuccess: () => void`, `type: DocumentTypeResponse`, `existingTypes: DocumentTypeResponse[]`.
   - Same layout as CreateTypeDialog but pre-populated from `type` prop.
   - `schemaText` initialized to `JSON.stringify(type.metadata_schema, null, 2)`.
   - Additional: "Delete Type" button in dialog footer (left side), `variant="destructive"`.
   - Delete flow: Clicking "Delete Type" opens a nested confirmation Dialog with title "Delete {type.name}?", body "This will remove the type definition. On confirm: call `deleteDocumentType(type.id)`, `toast.success("Type deleted")`, call `onSuccess()`, close both dialogs.
   - Parent type Select: filter out the current type and any types that have `parent_type_id !== null` (prevent grandchild).
