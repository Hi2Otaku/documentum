  <action>
    1. Create `src/app/tasks/bulk_operations.py`:
       - Celery task `execute_bulk_job(self, job_id: str)` with bind=True, max_retries=1, name="app.tasks.bulk_operations.execute_bulk_job"
       - Uses `asyncio.run(_execute_async(job_id))` pattern (same as audit_chain.py)
       - `_execute_async(job_id)`:
         - Creates session via `create_task_session_factory()`
         - Loads BulkJob by id, sets status="running", flushes
         - Iterates over job.document_ids one at a time:
           - For job_type "update": calls `document_service.update_document_metadata(db, uuid.UUID(doc_id), job.parameters.get("metadata", {}), job.created_by)`
           - For job_type "delete": checks retention via `retention_service.check_document_deletable`, then soft-deletes (doc.is_deleted = True), creates audit record
           - For job_type "lifecycle": calls `lifecycle_service.transition_lifecycle_state(db, uuid.UUID(doc_id), LifecycleState(job.parameters["target_state"]), job.created_by)`
         - Each item wrapped in try/except: on success append {"document_id": doc_id, "status": "success"} to results, increment success_count; on exception append {"document_id": doc_id, "status": "error", "error": str(e)}, increment failure_count
         - After all items: set status="completed" (or "failed" if failure_count == total_count), set completed_at=now(), set job.results = results list, commit
         - On any unhandled exception: set status="failed", commit, re-raise

    2. Create `src/app/routers/bulk.py`:
       - `router = APIRouter(prefix="/bulk", tags=["bulk"])`
       - `POST /update` — accepts BulkUpdateRequest body, calls `bulk_service.create_bulk_job(db, "update", req.document_ids, {"metadata": req.metadata}, str(current_user.id))`, returns EnvelopeResponse[BulkJobResponse]
       - `POST /delete` — accepts BulkDeleteRequest body, calls `bulk_service.create_bulk_job(db, "delete", req.document_ids, None, str(current_user.id))`, returns EnvelopeResponse[BulkJobResponse]
       - `POST /lifecycle` — accepts BulkLifecycleRequest body, calls `bulk_service.create_bulk_job(db, "lifecycle", req.document_ids, {"target_state": req.target_state}, str(current_user.id))`, returns EnvelopeResponse[BulkJobResponse]
       - `GET /jobs` — pagination params (page, page_size), calls `bulk_service.get_bulk_jobs`, returns EnvelopeResponse[list[BulkJobResponse]] with PaginationMeta
       - `GET /jobs/{job_id}` — calls `bulk_service.get_bulk_job`, returns EnvelopeResponse[BulkJobResponse], 404 if not found
       - All endpoints require `current_user: User = Depends(get_current_user)` (not admin-only — regular users can bulk-operate on documents)
