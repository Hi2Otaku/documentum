From src/app/schemas/monitoring.py (created in Plan 01):
```python
class ComponentHealth(BaseModel):
    name: str  # "database", "redis", "celery", "minio"
    status: Literal["healthy", "degraded", "unhealthy"]
    latency_ms: float | None = None
    details: str | None = None

class HealthResponse(BaseModel):
    status: Literal["healthy", "degraded", "unhealthy"]
    components: list[ComponentHealth]
    checked_at: datetime

class WorkerInfo(BaseModel):
    hostname: str
    status: str
    active_tasks: int
    processed: int
    pid: int | None = None

class QueueMetrics(BaseModel):
    queue_name: str
    depth: int

class SystemMetrics(BaseModel):
    workers: list[WorkerInfo]
    queues: list[QueueMetrics]
    total_active_tasks: int
    total_scheduled_tasks: int

class AlertRuleResponse(BaseModel):
    id: UUID
    name: str
    metric_name: str
    operator: str
    threshold: float
    enabled: bool
    notification_message: str | None
    created_at: datetime
```

API Endpoints (from Plan 01):
- GET /api/v1/monitoring/health -> EnvelopeResponse[HealthResponse]
- GET /api/v1/monitoring/metrics -> EnvelopeResponse[SystemMetrics]
- GET /api/v1/monitoring/alerts -> EnvelopeResponse[list[AlertRuleResponse]]
- POST /api/v1/monitoring/alerts -> EnvelopeResponse[AlertRuleResponse]
- PUT /api/v1/monitoring/alerts/{id} -> EnvelopeResponse[AlertRuleResponse]
- DELETE /api/v1/monitoring/alerts/{id} -> 204
