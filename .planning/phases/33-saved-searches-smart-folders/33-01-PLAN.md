   - list_saved_searches(db: AsyncSession, user_id: uuid.UUID) -> list[SavedSearch]: SELECT WHERE user_id = user_id AND is_deleted = False ORDER BY display_order ASC, created_at DESC
   - list_smart_folders(db: AsyncSession, user_id: uuid.UUID) -> list[SavedSearch]: Same but add filter is_smart_folder = True
   - get_saved_search(db: AsyncSession, search_id: uuid.UUID, user_id: uuid.UUID) -> SavedSearch | None: Single record by id + user_id
   - create_saved_search(db: AsyncSession, user_id: uuid.UUID, data: SavedSearchCreate) -> SavedSearch: Insert new record with user_id from auth
   - update_saved_search(db: AsyncSession, search_id: uuid.UUID, user_id: uuid.UUID, data: SavedSearchUpdate) -> SavedSearch | None: Partial update, return None if not found
   - delete_saved_search(db: AsyncSession, search_id: uuid.UUID, user_id: uuid.UUID) -> bool: Soft delete (set is_deleted=True), return True if found

2. Create `src/app/routers/saved_searches.py` per D-04:
   - router = APIRouter(prefix="/saved-searches", tags=["saved-searches"])
   - GET "/" — list_saved_searches for current user. Optional query param ?smart_folders_only=true calls list_smart_folders instead. Returns EnvelopeResponse[list[SavedSearchResponse]]
   - POST "/" — create_saved_search with SavedSearchCreate body, sets user_id from current_user.id. Returns EnvelopeResponse[SavedSearchResponse] with 201 status

   - DELETE "/{search_id}" — delete_saved_search. Returns 204 on success, 404 if not found
