    **src/app/services/analytics_service.py** -- SQL-based analytics (no new dependencies):
    - `get_execution_paths(db: AsyncSession, template_id: uuid.UUID | None = None, limit: int = 20) -> list[dict]`:
      Query ActivityInstance joined to ActivityTemplate, grouped by workflow_instance_id. For each completed workflow instance, collect the ordered sequence of activity names (ORDER BY started_at). GROUP BY the path string (comma-joined activity names), COUNT frequency, AVG total duration. Return top N paths by frequency. Use `template_id` filter if provided.
    - `get_cycle_times(db: AsyncSession, template_id: uuid.UUID | None = None, group_by: str = "activity") -> list[dict]`:
      When group_by="activity": Query ActivityInstance WHERE completed_at IS NOT NULL, compute duration = completed_at - started_at. GROUP BY activity_template.name, compute AVG, MIN, MAX, COUNT. Use func.percentile_cont for median if PostgreSQL, otherwise approximate with ordered subquery. For SQLite (tests), use simple AVG as median approximation.
      When group_by="template": Query WorkflowInstance WHERE completed_at IS NOT NULL, compute duration = completed_at - started_at. GROUP BY process_template.name, compute AVG, MIN, MAX, COUNT.
    - `get_bottlenecks(db: AsyncSession, template_id: uuid.UUID | None = None, limit: int = 10) -> list[dict]`:
      Query completed ActivityInstances, compute avg duration per activity, total executions per activity, and percentage of total workflow time consumed. ORDER BY avg_duration DESC. Join to ActivityTemplate for name, ProcessTemplate for template_name.
    - `get_analytics_summary(db: AsyncSession) -> dict`: Return total instances, completed, avg completion time, number of distinct paths, last_refreshed timestamp (from Redis cache key or None).
    - `refresh_analytics_cache(db: AsyncSession) -> None`: Call all three query functions, serialize results to JSON, store in Redis with key prefix `analytics:` and TTL 600s. Use `redis.asyncio` client from settings.redis_url.
    - All queries use `select()` style SQLAlchemy 2.0 syntax. Use `selectinload` where relationships needed.

    - `router = APIRouter(prefix="/analytics", tags=["analytics"])`
    - `GET /analytics/summary` -> `EnvelopeResponse[AnalyticsSummary]`: Calls `get_analytics_summary(db)`. Admin only via `get_current_active_admin` dependency.
    - `GET /analytics/paths` -> `EnvelopeResponse[list[ExecutionPath]]`: Accepts optional query params `template_id: uuid.UUID | None = None`, `limit: int = 20`. Calls `get_execution_paths(db, template_id, limit)`. Try reading from Redis cache first (`analytics:paths` or `analytics:paths:{template_id}`); if cache miss, query live. Admin only.
    - `GET /analytics/cycle-times` -> `EnvelopeResponse[list[CycleTimeStats]]`: Accepts optional `template_id`, `group_by: str = "activity"` (validate: "activity" or "template"). Calls `get_cycle_times(db, template_id, group_by)`. Cache-first pattern. Admin only.
    - `GET /analytics/bottlenecks` -> `EnvelopeResponse[list[BottleneckActivity]]`: Accepts optional `template_id`, `limit: int = 10`. Calls `get_bottlenecks(db, template_id, limit)`. Cache-first pattern. Admin only.
    - `POST /analytics/refresh` -> `EnvelopeResponse[dict]`: Triggers immediate cache refresh by calling `refresh_analytics_cache(db)`. Returns `{"status": "refreshed"}`. Admin only.
