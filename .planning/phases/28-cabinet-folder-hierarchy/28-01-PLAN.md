Functions to implement:

1. `async def create_cabinet(db: AsyncSession, name: str, description: str | None, created_by: str) -> Folder`:
   - Create Folder with `is_cabinet=True`, `parent_id=None`
   - `await db.flush()` + `await db.refresh(folder)`
   - Return folder

2. `async def create_folder(db: AsyncSession, parent_id: uuid.UUID, name: str, description: str | None, created_by: str) -> Folder`:
   - Verify parent exists and is not deleted via `_fetch_folder_or_404(db, parent_id)`
   - Create Folder with `is_cabinet=False`, `parent_id=parent_id`
   - flush + refresh, return folder

3. `async def get_folder(db: AsyncSession, folder_id: uuid.UUID) -> dict`:
   - Fetch folder via `_fetch_folder_or_404`
   - Compute path via `_get_folder_path(db, folder_id)` — returns list of `{"id": str, "name": str}` from root to this folder
   - Compute document_count via `select(func.count()).select_from(document_folders).where(document_folders.c.folder_id == folder_id)`
   - Return dict: `{"folder": folder, "path": path, "document_count": count}`

4. `async def get_folder_tree(db: AsyncSession) -> list[dict]`:
   - Single query: `select(Folder).where(Folder.is_deleted == False).order_by(Folder.name)`
   - Separate query for document counts: `select(document_folders.c.folder_id, func.count()).group_by(document_folders.c.folder_id)` — build `counts_by_id` dict
   - Build tree in Python: create `by_id` dict mapping `folder.id` to `{"id": str(f.id), "name": f.name, "is_cabinet": f.is_cabinet, "parent_id": str(f.parent_id) if f.parent_id else None, "document_count": counts_by_id.get(f.id, 0), "children": []}`. Then iterate: if `parent_id` in `by_id`, append to parent's children; else append to `roots` list.
   - Return `roots`

5. `async def rename_folder(db: AsyncSession, folder_id: uuid.UUID, name: str) -> Folder`:
   - Fetch via `_fetch_folder_or_404`, set `folder.name = name`, flush + refresh, return

6. `async def move_folder(db: AsyncSession, folder_id: uuid.UUID, new_parent_id: uuid.UUID) -> Folder`:
   - Guard: `new_parent_id == folder_id` raises HTTPException(400, "Cannot move folder into itself")
   - Guard: `await _is_descendant(db, folder_id, new_parent_id)` raises HTTPException(400, "Cannot move folder into its own subtree")
   - Verify new parent exists: `_fetch_folder_or_404(db, new_parent_id)`
   - Set `folder.parent_id = new_parent_id`, `folder.is_cabinet = False`
   - flush + refresh, return

7. `async def copy_folder(db: AsyncSession, folder_id: uuid.UUID, dest_parent_id: uuid.UUID | None, created_by: str) -> Folder`:
   - Fetch source folder. If `dest_parent_id` is None, use source's `parent_id`.
   - If `dest_parent_id` is not None, verify it exists via `_fetch_folder_or_404`
   - Collect all descendant folder IDs via CTE (same pattern as delete). Build ordered list of (source_folder, depth).
   - Create new folders mirroring the subtree. Use `id_map: dict[uuid.UUID, uuid.UUID]` to map old IDs to new IDs.
   - For each source folder in depth order: create new Folder with `name=source.name`, `description=source.description`, `parent_id=id_map.get(source.parent_id, dest_parent_id)`, `is_cabinet=False`, `created_by=created_by`
   - Copy document_folders rows: for each source folder, insert new rows with `folder_id=id_map[source.id]`, same `document_id`, `filed_at=now`, `filed_by=created_by`
   - flush, return the root copy folder

8. `async def delete_folder(db: AsyncSession, folder_id: uuid.UUID) -> None`:
   - Use recursive CTE to get all descendant IDs (anchor: `folder_id`, recursive: children where `is_deleted == False`)
   - Collect `ids_to_delete` list
   - If empty, raise 404
   - Bulk update: `await db.execute(update(Folder).where(Folder.id.in_(ids_to_delete)).values(is_deleted=True))`
   - Remove document_folders rows: `await db.execute(delete(document_folders).where(document_folders.c.folder_id.in_(ids_to_delete)))`
   - `await db.flush()`

9. `async def file_document(db: AsyncSession, folder_id: uuid.UUID, document_id: uuid.UUID, filed_by: str) -> None`:
   - Verify folder exists: `_fetch_folder_or_404(db, folder_id)`
   - Verify document exists: `select(Document).where(Document.id == document_id, Document.is_deleted == False)` — raise 404 if not found
   - Check not already filed: `select(document_folders).where(document_folders.c.document_id == document_id, document_folders.c.folder_id == folder_id)` — raise 409 if exists
   - Insert: `await db.execute(document_folders.insert().values(document_id=document_id, folder_id=folder_id, filed_at=datetime.now(timezone.utc), filed_by=filed_by))`
   - flush

10. `async def unfile_document(db: AsyncSession, folder_id: uuid.UUID, document_id: uuid.UUID) -> None`:
    - `result = await db.execute(document_folders.delete().where(document_folders.c.document_id == document_id, document_folders.c.folder_id == folder_id))`
    - If `result.rowcount == 0`, raise 404
    - flush

11. `async def get_folder_documents(db: AsyncSession, folder_id: uuid.UUID, page: int = 1, page_size: int = 20) -> tuple[list[Document], int]`:
    - Verify folder exists
    - Count: `select(func.count()).select_from(document_folders).where(document_folders.c.folder_id == folder_id)`
    - Query: `select(Document).join(document_folders, Document.id == document_folders.c.document_id).where(document_folders.c.folder_id == folder_id, Document.is_deleted == False).offset((page-1)*page_size).limit(page_size)`
    - Return (documents, count)

12. `async def get_document_folder_ids(db: AsyncSession, document_id: uuid.UUID) -> list[str]`:
    - `select(document_folders.c.folder_id).where(document_folders.c.document_id == document_id)`
    - Join with Folder to exclude deleted folders: `.join(Folder.__table__, document_folders.c.folder_id == Folder.__table__.c.id).where(Folder.__table__.c.is_deleted == False)`
    - Return `[str(row[0]) for row in result.all()]`

Internal helpers:

`async def _fetch_folder_or_404(db: AsyncSession, folder_id: uuid.UUID) -> Folder`:
  - `select(Folder).options(selectinload(Folder.parent)).where(Folder.id == folder_id, Folder.is_deleted == False)`
  - Raise HTTPException(404, "Folder not found") if None

`async def _get_folder_path(db: AsyncSession, folder_id: uuid.UUID) -> list[dict]`:
  - Recursive CTE: anchor = select Folder.id, Folder.name, Folder.parent_id, literal_column("0").label("depth") where id == folder_id and is_deleted == False, `.cte(name="ancestors", recursive=True)`
  - Recursive term: select parent_alias.c.id, parent_alias.c.name, parent_alias.c.parent_id, (anchor.c.depth + 1).label("depth") joining Folder.__table__.alias("p") on parent_alias.c.id == anchor.c.parent_id
  - `ancestors_cte = anchor.union_all(recursive)`
  - Select id, name ordered by depth DESC (root first)
  - Return `[{"id": str(row.id), "name": row.name} for row in result.all()]`

`async def _is_descendant(db: AsyncSession, folder_id: uuid.UUID, candidate_id: uuid.UUID) -> bool`:
  - Recursive CTE: anchor = select Folder.id where parent_id == folder_id and is_deleted == False, `.cte(name="descendants", recursive=True)`
  - Recursive term: select Folder.id joining anchor on Folder.parent_id == anchor.c.id where is_deleted == False
  - `descendants_cte = anchor.union_all(recursive)`
  - Check if candidate_id is in the CTE results
  - Return True/False
